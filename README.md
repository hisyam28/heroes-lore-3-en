# Heroes Lore 3 — English Localization

Community English localization with compact text, readable menus, and performance fixes.

**[Download the latest APK](https://github.com/hisyam28/heroes-lore-3-en/releases/latest)**

The latest APK is **v1.1.4**, including CLR cancellation, improved enemy-level
spacing, refreshed title artwork and launcher icon, and full `YES` labels.
See the [update details](reports/system-title-icon-draft.md).

- English dialogue, quests, menus, enemy names, item descriptions, and skills.
- Compact labels such as `NM`, `EFC`, and `OTHR`, with a smaller Latin font.
- English native settings, centered character-save rows, and compact `NET STORE` navigation.
- Restored graphics acceleration and corrected skill detail formatting.
- Guarded confirmation-popup touch handling, refreshed launcher icon, and a
  title wordmark with the subtitle `STIGMATA OF EARTH`.
- Compact save notifications and enemy-level digits that fit their HUD frame.
- Validation for resource structure, text bounds, and unchanged gameplay metadata.

See the [release review](reports/optimized-build-review.md) for coverage and known
limits, or [development notes](docs/development.md) for the local tooling.
On-device testing is still needed for visual issues and performance across devices.
